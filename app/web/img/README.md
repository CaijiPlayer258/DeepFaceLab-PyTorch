# 图片资源

| 文件 | 用途 | 说明 |
|---|---|---|
| `logo.png` | 顶栏 / 关于页的 DF 标志 | 直接使用 |
| `bili-mark.png` | 登录页扫码卡片下方「使用 哔哩哔哩 扫码授权登录」里的选字标 | **派生资源**，见下 |
| `src/bilibili.png` | 哔哩哔哩选字标原始素材 | 不参与渲染，只留档 |

## bili-mark.png 是怎么来的

从 `src/bilibili.png` 产出：

1. 裁切到 `(35, 17) – (190, 86)`，去掉四周留白
2. 整体重上色为品牌粉 `#D2527C`（保留原 alpha）
3. 等比缩放到 `160 × 72` 存 PNG

改色或换图后记得同步更新 `app/web/css/app.css` 里 `.ccap .bili` 的高度（现在是 21px，
它决定了文字里这个标看起来和正文一样大）。
