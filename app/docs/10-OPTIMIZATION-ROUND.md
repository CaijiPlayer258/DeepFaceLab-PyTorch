# 10 · 本轮优化总览（4.1-beta）

测试机：**RTX 5070 Laptop**（性能约等于桌面 RTX 4060）。所有数字均为本机实测，
不是理论值；单位是毫秒/微秒，**没有纳秒级的项**。

## 一、过滤器：三个模式重做

| 模式 | 算法 | 说明 |
|---|---|---|
| 模糊 | 高频/低频能量比 E(b0)/E(b2) + 按分位淘汰 | 对齐 4.0 新版度量（旧实现是拉普拉斯方差，量纲已废弃） |
| 人脸身份 | ArcFace embedding + IVF 粗量化 + DBSCAN 语义 | 20 万张 8.55 s，50 万张 39.5 s，簇数精确 |
| 重复图 | 64 位感知哈希 + 多索引哈希（MIH） | 精确算法，10 万哈希 0.85 s |

- 打不开的文件现在**每个模式都会顺带清掉**，不再是一个独立模式；
- 所有命中项只移动到 `_trash`，可撤销（不提供直接删除）。

## 二、去掉的选项

| 去掉的 | 原因 |
|---|---|
| 位置聚类 | 4.0 时期几乎无人使用 |
| 「坏图」独立模式 | 并入上面三个模式 |
| 模型选择（mbf/r50） | 固定 w600k_mbf：13 MB，比 r50 快 5 倍，精度对聚类足够 |
| 目标分辨率等排序参数 | 4.0 的排序器并不存在这些参数 |

## 三、实测速度

| 环节 | 优化前 | 优化后 | 关键手段 |
|---|---|---|---|
| embedding 提取 | 4.79 ms/张（CPU） | **0.377 ms/张** | 直接 TRT fp16 + bs=32 + 解码/推理流水线 |
| 应用遮罩 | 1.658 ms/张（8 线程） | 保持，XSeg 禁用 CUDA Graph 防上下文损坏 | — |
| 检测器 TinyMog | 3.91 ms | **2.98 ms** | GPU 预处理 + 解码重写 |
| 特征点 2D106 | 0.85 ms | **0.711 ms** | 同上 |
| 模糊扫描（1204 张） | 5.64 s | **1.07 s** | 一次解码算全部特征 + 线程池 |
| 重复扫描（1204 张） | 2.89 s | **0.96 s** | 向量化 + MIH |
| 人脸聚类 | 分钟级 | **8.55 s / 20 万** | IVF + nprobe 2~3 + 格内 top-k |

## 四、UX

- 数据处理页合并为**单卡片 + 顶部切换**（原来三个同构卡片竖排）；
- 新增二级运行页（进度、速度、剩余时间），与「人脸提取」一致；
- 侧栏「运行中」改为**百分比胶囊**（折叠时贴在图标角上）；
- 图表跟随主题、Y 轴 20% 留白、刻度更细；
- **引擎编译页接上数据**（此前前端从未调用 `/api/engines`，页面永远空白）；
- 修复侧栏切页丢状态：`extract-run` / `dataset-run` 未登记进路由四张表。

## 五、修掉的 bug

- **DFLJPG 元数据写入破坏 JPEG**：APP15 现在追加在 EOI 之前，不再重排段序
  （旧实现在遇到 JPEG 填充字节时会把扫描数据复制一遍，文件翻倍且打不开）；
- 读取端同样支持文件尾的 APP15；
- 提取进度：续跑时「已对齐人脸 / 人脸速度」不再恒为 0；
- CSS 里一个未闭合的注释曾吞掉文件后半部分（约 1200 行，含合成器整段样式）；
- 数据集页切换模式时重复标题闪现、页面切换硬切无动画。
