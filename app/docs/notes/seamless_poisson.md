# seamless 合成的泊松求解：一次阶段性实验

目标：把 `cv2.seamlessClone`（CPU，逐脸一次调用）换成 GPU 上的频域泊松解，看能否既快又等价。
结论：**频域解在矩形域上正确，但在不规则遮罩上会出伪影；正确算子（遮罩域 Dirichlet）本身不便宜，
这条路要成立必须先有一个快得多的问题求解器，而不是把 FFT 直接套上去。**

## 1. 三个实现

| 记号 | 做法 | 复杂度 |
|---|---|---|
| cv2 | `cv2.seamlessClone(..., NORMAL_CLONE)` | 稀疏线性系统，C++ |
| FFT | 在遮罩的外接矩形上解 Δf = Δsrc，边界取 dst 边框，DST-I 对角化 | O(N log N) |
| CG | 只在遮罩内解，边界取 dst 的遮罩轮廓 | O(N·iter) |

方程是 ∇f = ∇src（域内）与 f = dst（边界），即 Δf = Δsrc。

## 2. 已知答案的检验：src = dst + 常数

此时解必须精确等于 dst（梯度相同、边界相同）：

```
cv2 与 dst 平均差 0.596，最大 2
fft 与 dst 平均差 0.008，最大 2
cg  与 dst 平均差 0.431，最大 3
```

三个都过。说明实现方向没错。

## 3. 真实场景：两张对齐人脸 + 椭圆遮罩

![seamless 三种实现](seamless_face.png)

从左到右：dst、src、cv2、FFT、CG。

```
cv2 vs fft   max=221  mean=22.7  psnr=15.4 dB
cg  vs cv2   max=221  mean=20.8  psnr=15.9 dB
cg  vs fft   max=177  mean=9.9   psnr=22.6 dB

耗时（512² 人脸、椭圆遮罩）
cv2 = 29.4 ms    fft = 21.3 ms    cg = 5581 ms（Python 逐元素组装矩阵，未优化）
```

FFT 那一列在遮罩上缘出现暗楔——不是为了好看，是**解法本身错**：

- FFT 要求矩形域，于是把「遮罩外接矩形的边框」当成 Dirichlet 边界；
- 椭圆只有四个点落在该矩形边框上，其余边框像素仍在遮罩内，被强行钉成 dst 的值；
- 矩形内、椭圆外的区域又被当作未知量自由浮动，等于在遮罩里挖了一条缝。

CG 把未知量限制在遮罩内、其余钉成 dst，结果与 cv2 视觉一致；但它慢了两个数量级，
原因是我用 Python 循环组装稀疏矩阵，不是算法本身的上限。

## 4. 这个实验真正的收获

1. 「泊松合成搬到 GPU」在数学上没有问题，**问题在域**：不规则遮罩不能直接上 FFT。
2. cv2 的 29 ms 已经是优化过的稀疏求解，想赢它需要一个好的预条件（多重网格 / AMG）而不是换个变换。
3. 已知答案的检验很便宜（一次 0.6 秒），值得先做——否则会误判是「实现细节差异」。
