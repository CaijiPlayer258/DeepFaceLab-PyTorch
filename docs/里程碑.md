按完成时间倒序。只记真实验收过的节点。

## 2026-10-25 · 界面布局与交互设计完成

- 参数页统一成四段式：**标签 · 说明 · 控件**；控件列固定 220px，行高统一 45px
- 参数页吸顶搜索（滚多远都够得着）、吸底操作条（开始训练不用翻到底）
- 下拉框主题化：替掉原生 select 的弹层，开合有过渡、配色走主题变量
- 冻结层按架构过滤：LIAE 只显示 inter_AB/inter_B，DF 只显示 inter/输出；
  DFLarge / LIAELarge 专属项（瓶颈、A/B 遮罩、共享）在 4.1 全部隐藏
- 设备下拉直显 GPU 型号与显存（GET /api/devices），设备卡固定在数据集参数之后
- 路径行可编辑；不带盘符的路径相对仓库根目录解析
- 主题色定稿：Linear 色系种子 **#5D6CCF**，只用于主按钮与进度条，其余保持黑白

## 2026-10-25 · 提取器完工

- 检测器双档：**高精度 RetinaFace_10g** / **高性能 TinyMog**（谁的档位谁负责，不跨档兜底）
- 对齐：动态分辨率（边长 = 检测框长边 × 2，无上下限），越界填纯黑
- 流水线：解码 → 检测 → 对齐/编码/写盘三级并行，1080×1920 源实测 84~93 帧/秒
- 帧跳跃语义修正：**1 = 逐帧**（不再挂 fps 滤镜）；N = 隔 N-1 帧取 1 帧
- 四格实时统计：帧速度 / 人脸速度 / 已对齐人脸 / 已处理帧
- 数据集过滤器：清晰度 / 噪点 / 曝光 / 遮挡（hull 与 XSeg 差值）/ 重复图
