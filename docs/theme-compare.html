主题色对比 · Linear 体系 vs Material 3

同一套种子色，分别按两套体系生成 token，再画成同一个界面（侧栏 + 参数卡 + 输入框 + 开关 + 进度条 + 按钮）。
Linear：一条中性灰阶（5 档）+ 单一强调色 + 状态色，描边细、层次靠灰阶拉开。
Material 3：五条色阶（primary / secondary / tertiary / neutral / neutral-variant）× 13 阶，语义角色二十多个， 容器色是"带色相的表面"，层级靠色阶差。

Linear 体系单一强调色 · 中性灰阶

Material 3五色阶 · 语义角色

怎么选（就这个应用而言）

Linear 体系
· 变量少：约 15 个，中性灰阶 5 档 + 单一强调色 + 状态色
· 强调色保持饱和（深色下按钮仍是实心靛蓝 + 白字）
· 层次全靠灰阶和 1px 描边，信息密度大的表格/参数页不糊
· 需要自己定 accent 的 hover / press / soft 三档
Material 3
· 变量多：五条色阶 × 13 阶，语义角色 20 多个
· 容器色带色相（surface-container 是"带颜色的表面"），组件有材质感
· 深色模式 primary 取 tone 80（浅色调），按钮是浅底深字，整体更柔
· 对比度偏低，密集列表里"哪些是可点的"不如 Linear 直观
