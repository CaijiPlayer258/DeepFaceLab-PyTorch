4.0.8.3
- 人脸集筛选与排序的清晰度指标换成「高频/低频能量比」= E(b0)/var(b2)
  · 旧版拉普拉斯方差测的是【绝对值】，把内容对比度和锐度混在一起 ——
    高对比的模糊图会拿到比低对比清晰图更高的分，阈值无法跨图通用
  · 实测（150 张对齐人脸 + 合成高斯模糊，XSeg 遮罩内）：
    模糊分离度 2.53 -> 3.31（+31%），内容变异系数 CV 0.224 -> 0.240（基本持平）
  · 分母用 var 而不是 mean(b^2)：b2 是低频残差、带着画面亮度，实测 DC 占了
    mean(b2^2) 的 96.5%，不去掉的话指标会退化成「亮度归一化的高频能量」；
    去掉 DC 后分离度 2.81 -> 3.31、CV 0.264 -> 0.240
  · 掩码改为只用于【选择统计像素】，不再 image * mask
    （后者会在掩码边界制造强度极高的假边缘，主导拉普拉斯响应）
  · 新增噪声补偿：噪声=高频=高分，实测 sigma_n=0.04 会让分数虚高 4.97 倍，
    而「多轮取 high」的筛法会把噪声图一路富集上来
- Filter（--mode blur）：4 档阈值不再写死（旧的 10/20/40 是拉普拉斯方差的量纲）
  · 默认按本数据集 10/30/60 分位切；--absolute 改用合成模糊定绝对门槛
  · 报告新增「中位等效模糊 sigma」一列，让分级有绝对含义
  · 新增 --train-res（默认 256，应与训练分辨率一致）
- Sorter（--method blur）：分数越高 = 越清晰 = 序号越靠前
  · 重命名后 sorted_00000 最清晰，直接开文件夹看图删即可，不需要 GUI
  · 结果写入 metadata.h5，字段名 sharpness_br{train_res}；第二次跑直接读缓存
  · 新增 --train-res；--motion-blur 废弃（新指标对运动模糊同样敏感）
- 修复：onnxruntime 改为惰性导入，GUI 进程不再因原生扩展 DLL 初始化失败而崩溃
  · Filter / Sorter 原来在模块顶部直接 import onnxruntime；即使去掉，
    facelib/__init__ 仍会经 FaceDetector 把它拽进来
  · FaceDetector 改为 PEP 562 惰性加载，其余名字与调用方式完全不变
  · 实测：Qt 之后 import Filter / Sorter 从「WinError 1114 崩溃」变为正常导入，
    且 onnxruntime 全程未加载；Extractor / Util / FacesetResizer / DFLJPG 全部照常

4.0.8.2
- 新增「预训练单解码器支路」（DF 架构 + 预训练时生效，默认关闭）
  · 预训练只跑 src 支路（encoder + inter + decoder_src），完全跳过 decoder_dst
    的前向与反向，并把 decoder_dst 从优化器参数表摘除，省下其优化器状态
  · 保存时自动把 decoder_src 权重复制到 decoder_dst（两解码器结构一致，复制无损）
  · 预训练两条支路读取同一份多身份数据集，故与「训练 dst 支路再复制给 src」等价
  · 收益：省掉一条支路的算力与显存，可开出更大的 batch（取舍见设计记录文档）
- 恢复预训练开关：此前 4.0.8.1 将 pretrain 强制关闭，现恢复为可加载选项并重新提供询问入口
- 修复：GUI 写回模型选项时遗漏 pretrain / pretrain_single_decoder（未登记进 _runtime_opts），
  导致界面开关不生效、模型摘要仍显示「预训练: False」
- 修复：预训练结束转正训练时迭代计数未归零，会让 lr 调度错位（对齐原 pretrain_just_disabled 语义）
- 预训练集默认使用 dst 训练集（GUI 无该选项时的默认行为；CLI 的 --pretraining-data-dir 可覆盖），
  不再因未指定而抛「未定义 pretraining_data_path」
- 预训练集不做格式限制：既支持「含 faceset.pak 的打包目录」，也支持「散装 DFLJPG 对齐人脸目录」
  （两种由 SampleLoader / SampleLoaderV4 自动识别）；直接把 faceset.pak 文件本身传入时，
  自动改用其所在目录
- 模型摘要「训练设置」新增「单解码器」一行，便于确认开关是否真的生效
- 性能：训练步内的 pred_src_dst / pred_src_dst_no_code_grad 改为「按需计算」。
  这两个换脸输出只服务 face_style / bg_style；两者都为 0 时（默认配置）没有任何
  loss 会读它们，原实现却每步照跑 —— decoder_src 每步跑 3 次（实际只需 1 次），
  解码器前向等于翻倍。现在仅在对应 style 开启时才计算；预览（AE_view）也只算
  它真正要用的那一次（不再算 no_code_grad）。
  涉及 _forward_df / _forward_liae / train_one_step / _xla_core / AE_view。
